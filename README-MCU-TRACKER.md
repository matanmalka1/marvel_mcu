# MCU Watch Tracker

הפרויקט נמצא בתיקייה [`mcu-watch-tracker`](./mcu-watch-tracker).

זוהי אפליקציית Next.js בעברית למעקב צפייה בסרטי MCU, עם סדר כרונולוגי וסדר יציאה, סינון, Undo והגנה מפני ספוילרים.

להוראות התקנה, פיתוח, בדיקות ועדכון נתונים ראו את [תיעוד הפרויקט](./mcu-watch-tracker/README-MCU-TRACKER.md).
